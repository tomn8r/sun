Instructions

  • Auto-Set: Use the target button (⌖) to lock in the current sun position as a Min/Max limit.
  • Colors: Green=Sunlit, Red=Shaded, Gold=Conditions Met.
  • Custom Model: Open "House Model" -> "Upload .GLB" for CAD files.
  • Save: "Save Settings" stores data in browser.
